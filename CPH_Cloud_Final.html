⚙️ Configuration Firebase requise

Ce fichier est prêt à utiliser Firebase (base de données cloud temps réel). Il faut juste connecter votre projet Firebase en 3 étapes :

Étape 1 — Créer un projet Firebase (gratuit)
Aller sur console.firebase.google.com → + Ajouter un projet → Donner un nom (ex: cph-boucle-de-seine) → Désactiver Google Analytics → Créer.
Étape 2 — Activer Firestore et Storage
Dans le menu gauche : Firestore Database → Créer base de données → Mode test → Sélectionner région europe-west1.
Puis : Storage → Commencer → Mode test.
Étape 3 — Copier la configuration
⚙️ Paramètres du projet → Vos applications → </> Web → Enregistrer l'app → Copier le bloc firebaseConfig → Ouvrir ce fichier HTML avec un éditeur de texte → Remplacer les valeurs VOTRE_... dans la section CONFIG.
Étape 4 — Importer vos données existantes
Ouvrir votre ancien fichier HTML → Exporter JSON → Revenir ici → Cliquer 📥 Importer JSON.

Ce message disparaîtra une fois la configuration correctement remplie.
